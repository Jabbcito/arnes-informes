## Disparador

Título y variables ya confirmados.

## Qué hace

1. Formula búsquedas concretas a partir de las variables de estudio.
2. Consulta exclusivamente las bases listadas en `../../fuentes-permitidas.md` (o un enlace específico que el alumno pegue).
3. Para cada hallazgo registra en `fuentes/investigacion.md`: afirmación útil, autor, año, enlace/DOI, fragmento de evidencia, uso previsto (antecedente o base teórica) y estado `PENDIENTE DE VERIFICAR`.
4. Si no encuentra evidencia suficiente para una variable, lo dice explícitamente y sugiere ampliar la búsqueda o agregar una fuente en `../../fuentes-permitidas.md`.

## No hace

No inventa fuentes. No redacta el informe. No marca ninguna fuente como `VERIFICADA` — eso solo lo hace el alumno al abrir el enlace y confirmar autor, año y pertinencia.
