# Qué omitir de `tesis/contenido/` en modo informe

`../estructura-informe-maestra.md` dice en su párrafo inicial que el modo informe reutiliza el mismo estándar de `tesis/contenido/` pero "quitando las piezas exclusivas de una tesis formal". Esta tabla reemplaza esa instrucción general por una lista explícita, archivo por archivo — para que el agente no tenga que decidir en vivo, cada vez, qué omitir.

**Regla de uso**: para cada archivo de `../../tesis/contenido/`, revisar la columna "Qué hacer en informe" ANTES de aplicarlo. Si dice "no se usa", ese archivo se salta por completo — no se lee ni se sigue su protocolo.

| Archivo de `tesis/contenido/` | Qué hacer en modo informe |
|---|---|
| `titulo-y-variables.md` | Se usa completo, incluida la salvaguarda de ejes seguros/riesgosos al reformular el título si no está disponible — un informe también puede toparse con un título casi idéntico a uno ya entregado en el curso. |
| `antecedentes.md` | Se usa, pero fusionado con `bases-teoricas.md` en una sola sección "Marco teórico / Antecedentes" (ver sección 6 de `../estructura-informe-maestra.md`) — no como capítulos separados como en tesis. |
| `bases-teoricas.md` | Igual que arriba: fusionado con antecedentes, sin la subdivisión formal de tesis. |
| `hipotesis.md` | **No se usa** — un informe descriptivo/monografía no formula hipótesis estadísticas. Si el trabajo sí es empírico con diseño correlacional/experimental, se usa completo (poco común en "informe", pero posible). |
| `instrumento-y-muestra.md` | Se usa solo si el trabajo incluye recolección de datos propia (encuesta, entrevista). El gate de juicio de expertos (V de Aiken) y de confiabilidad (alfa) sigue aplicando igual que en tesis si se construye un instrumento — no se simplifica el rigor solo por ser informe. |
| `tipos-de-instrumento.md` | Igual que arriba — se usa completo si aplica instrumento. |
| `matriz-de-consistencia.md` | **No se usa** como documento formal aparte — el informe no exige una matriz de consistencia visible, pero los objetivos/variables/conclusiones deben seguir siendo coherentes entre sí (se verifica igual, solo que sin la tabla formal). |
| `metodologia.md` | Se usa solo si el trabajo es de investigación empírica (sección 8 de `../estructura-informe-maestra.md` ya lo dice); se omite población/muestra/muestreo formal si el trabajo no lo requiere. La pregunta de ética real de comité institucional (ver v17) sigue aplicando si el trabajo involucra población vulnerable, aunque sea un informe corto. |
| `recoleccion-datos-principal.md` | Se usa solo si hubo instrumento (ver `instrumento-y-muestra.md` arriba). |
| `introduccion.md` | Se usa completo. |
| `objetivos.md` | Se usa completo (objetivo general + específicos presentados como opciones, regla 22). |
| `resultados.md` | Se usa completo si hay datos propios; si el informe es puramente documental/descriptivo sin datos propios, se fusiona con "Desarrollo" (sección 9 de `../estructura-informe-maestra.md`). |
| `discusion.md` | **No se usa como capítulo aparte** — se fusiona con Desarrollo/Resultados (sección 9), tal como indica `../estructura-informe-maestra.md`. El contenido de fondo (contrastar contra el marco teórico, no repetir resultados) sigue aplicando dentro de esa fusión. |
| `conclusiones.md` | Se usa completo. |
| `recomendaciones.md` | Se usa completo. |
| `resumen-abstract.md` | Se usa solo si la rúbrica lo pide — no es estándar en informes cortos/ensayos, sí en informes de investigación más extensos. |
| `tablas-y-figuras.md` | Se usa completo para el formato de cada tabla/figura individual (numeración, "Nota.", captions), pero **sin índice separado de tablas/figuras** (sección 3 de `../estructura-informe-maestra.md`: solo el índice general). |
| `dedicatoria-agradecimiento.md` | **No se usa** — sección exclusiva de tesis. |
| `anexos.md` | Se usa completo si el trabajo tiene instrumentos/evidencia que anexar; sin las declaratorias de autenticidad/originalidad firmadas (esas son exclusivas de tesis). |

## Qué es exclusivo de tesis y no tiene archivo propio para omitir

Estas piezas ya están descartadas por el propio párrafo introductorio de `../estructura-informe-maestra.md` y no requieren ninguna acción adicional: declaratorias de autenticidad/originalidad firmadas por asesor y autores, índices separados de tablas y figuras, operacionalización formal de variables (tabla dimensiones/indicadores/ítems) más allá de lo que ya pide un instrumento si lo hay.
